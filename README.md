# CRTV_SHELVES

A social media curation app. Create ranked "shelves" for your favorite TV shows, movies, music, books, and more — then share them with friends.

Built on the T3 Stack: **Next.js 15 · TypeScript · Drizzle ORM · Vercel Postgres · Tailwind CSS v4 · Clerk**

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm (`npm install -g pnpm`)
- Vercel account (for Postgres)
- UploadThing account (optional — only for image uploads)
- Clerk application (for auth keys)

### 1. Install dependencies

```bash
pnpm install
```

### 2. Pull environment variables

```bash
vercel env pull .env.local
```

Confirm `POSTGRES_URL` is present in `.env.local`, and add your Clerk keys
(`NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`) if they are not
already set for the environment you pulled. See `.env.example` for the full list.

> `drizzle-kit` does not read `.env.local` on its own — only `.env`. `drizzle.config.ts`
> loads it explicitly, so `pnpm db:push` works with a standard `vercel env pull`.

### 3. Push the database schema

```bash
pnpm db:push
```

### 4. Start the dev server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
